# 报错手册（持续更新）—— 症状 / 原因 / 解决

> 用法：报错来了，先看"报错名"，对号入座；记不住就翻这页。

---

## 一、前端 JS 报错

### 1. `ReferenceError: xxx is not defined`
- **意思**：找不到叫 `xxx` 这个名字
- **常见原因**（按频率排）：
  - 拼写错：`fetch` 打成 `feetch`
  - 变量名前后不一致：循环定义 `litem`，用的时候却写 `item`
  - `for` 循环那行漏了 / 写错（导致变量没被发明出来）
  - 大小写错：JS 区分大小写，`Fetch` ≠ `fetch`
- **解决**：检查那个名字——拼写对不对、前后叫法一不一致、定义它的那一行在不在

### 2. `TypeError: Cannot set properties of null (setting 'innerHTML')`
- **意思**：给 null 设属性失败 = 你 `getElementById(...)` 找到的是 null（**页面上没这个 id**）
- **常见原因**：
  - HTML 没给那个标签加 `id="..."`（或 id 值不同）
  - id 拼写和 JS 里 `getElementById("...")` 不一致
  - `<script>` 放在 `<body>` **前**了：页面内容还没加载，元素还不存在
- **解决**：① 确认 HTML 有对应 id；② id 拼写一致；③ **把 script 移到 `</body>` 前**

## 二、后端 / 环境报错

### 3. `ModuleNotFoundError: No module named 'xxx'`
- **意思**：找不到叫 `xxx` 的库
- **常见原因**：本机有多个 Python，依赖装进了**另一个** Python（比如 `pip` 指向 3.14，`python` 是 3.13）
- **解决**：`python -m pip install xxx`（用 `python -m` 对齐解释器）；确认装进的是你启动用的那个 Python

### 4. `JSON decode error`（命令行 curl 传中文时）
- **原因**：PowerShell 命令行传含中文的 JSON 会因编码损坏
- **解决**：改用 python 脚本测，或用接口自带的 `/docs` 页测（不碰命令行中文）

## 三、通用排查顺序（每次报错都这么走）
1. **读报错第一行**：是"名字/拼写问题"还是"逻辑问题"？
2. **`is not defined`** → 名字拼错 / 变量名前后不一致
3. **`Cannot set ... null`** → 找不到元素 / 对象
4. 改完 **刷新** 再验证（不要只看改没改，要看页面结果）
5. 一个报错解决后，**下一行可能还有报错**——一个个来

---

## 四、一句话总结
> **95% 的前端报错是"名字对不上"：拼错、前后不一致、id 没加。先查名字，再查位置，别急着改逻辑。**
