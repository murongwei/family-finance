## 0 层 · Web 地基（最根本，先懂这个）
```
你填、你点 → 浏览器打包成"请求"(HTTP) → 发给服务器(端口8000)
           → 服务器处理后从数据库取/存 → 回"响应"给你页面
```
- 请求-响应：浏览器发话，服务器回话
- HTTP 方法：GET=读东西、POST=写东西
- 端口：8000 = 服务器在你电脑上的"门牌号"
- 前后端分离：前端管界面，后端管数据，中间用 HTTP 传 JSON

## 1 层 · Python 基础 —— 大部分已有 ✅
- 已有（刷题练过）：变量/类型/函数/列表/字典
- 后端要补（刷题没碰）：class 类、import 模块/包、异常处理

## 2 层 · API/接口（后端核心，全新）
- URL 是一扇窗口：路径(/api/entries) + 方法(GET/POST)
- 路由 = 告诉后端"这个 URL 该干嘛"：@app.get("/") 装饰器
- JSON = 前后端传话的统一格式
- 请求体(body) = POST 时把数据打包发过去的那包
- /docs = FastAPI 白送的接口说明书

## 3 层 · 数据库 SQLite（全新）
- 表 = 一张账本表格（列叫"字段"）
- SQL 四句：CREATE(建表) / INSERT(加行) / SELECT(查行) / DELETE(删行)
- 主键 id = 每一行的身份证（自动+1）
- 参数化 ? 占位 = 安全地把数据填进 SQL（防注入）
- 连接 = 打开数据库文件 → 读写 → 关

## 4 层 · 前端 HTML/CSS（全新）

- CSS = 皮肤：class、flex/grid 布局、颜色/圆角/阴影
- 看 A 版 index.html 就是这两样写的
- 接真实数据才轮到 JS 的 fetch（那是 P1 的新知识）

## 已学笔记 · A Web地基 + B 最小demo（11-04）

### A 核心（Web 地基）
- 请求-响应：浏览器发话，服务器回话
- 前后端分离：前端管界面，后端管数据，靠 HTTP + JSON 对话
- 8000 端口 = 后端（回 JSON）；index.html = 前端（页面）

### B 深讲：为什么这么写（把概念落成代码的规则）
- **FastAPI = Web 框架**：把"你写的 Python 函数"变成"别人能通过网址访问的服务"。框架主导，你填内容。它替你干：接 HTTP、路由、/docs、数据校验、并发。
- **app = FastAPI()**：`FastAPI` 是"图纸"(类)，`()` 是"施工"(实例化)，`app` 是"盖好的房子"(后端本体)，路由都登记在 app 上。
- **@app.get("/")**：`@`=装饰器(把下面函数交给@后的东西登记)；`app.get`=登记 GET 路由的方法；`"/"`=路径(根路径/首页)。
- **访问流程**：GET / → FastAPI 查登记表 → 调 home() → return 字典 → FastAPI 打包 JSON → 回浏览器。
- **加接口**：每组 `@app.get("路径")` + 函数放一起(同层)；登记了才存在，没登记=404。
- **127.0.0.1** = 本机自己；**8000** = 端口(uvicorn 默认)；改端口加 `--port 8080`。

### P1-1 静态托管（11-04，已跑通）
- 目标：让 8000 显示页面（把 frontend 文件夹"送"给浏览器）
- 概念：
  - **mount(挂载)** = 把某个目录"贴"到某个 URL 前缀下，FastAPI 直接把里面文件发给浏览器
  - **StaticFiles** = 静态文件服务工具（html/css/js 原样发，不用算）
  - **html=True** = 访问 `/` 自动返回 index.html
- **关键坑（记牢）**：**同一 URL 只能一个处理器；显式路由优先，mount 兜底**。
  → main.py 原本的 `@app.get("/")` root() 占着 `/` 返回 JSON，mount 排不上 → **必须删掉 root()**，页面才接管 `/`
- 代码：`FRONTEND_DIR = Path(__file__).resolve().parent.parent / "frontend"` + `app.mount("/", StaticFiles(directory=FRONTEND_DIR, html=True), name="frontend")`
- 成果：127.0.0.1:8000 显示墨绿页面；/docs 接口仍在

### P1-2a 前端 fetch 拿数据（11-04，已验证）
- 概念：JS = 前端编程语言(肌肉，让页面会做事)；fetch = 前端发 HTTP 请求(把 /docs 手动点变成代码自动)；await = 等服务器响应；res.json() = 把响应解析成 JSON；console.log = F12 控制台打印验证
- 代码：`const res = await fetch("/api/entries")` → `const data = await res.json()` → `console.log(data)`
- **关键坑（记牢）：拼写错误** —— `feetch` 应为 `fetch`。报错 `ReferenceError: xxx is not defined` = "找不到这个名字" = 99% 拼写错（写错/少字母/大小写错，JS 区分大小写）
- 成果：控制台打印 `(2) [{…},{…}]` = 拿到数据库真实 2 条账目，fetch 通路验证成功

### P1-2b 前端渲染真实数据（11-04，已完成）
- 概念：`getElementById("id")` = 按 id 找到页面元素；`innerHTML` = 往元素塞 HTML；`for (const item of data)` = 遍历数组；模板字符串 `` `${item.xxx}` `` = 把变量插进字符串；`item.note || ""` = 空值兜底
- 代码：`list.innerHTML = ""` 清空 → `for` 循环拼一段 HTML `+=` 塞入
- **关键坑1（变量名）**：循环定义 `litem` 却写 `item` → `item is not defined`。**名字前后必须一致**
- **关键坑2（位置）**：`<script>` 必须放 `</body>` **前**（等 DOM 加载完再执行 JS，否则 `getElementById` 为 null）
- **关键坑3（字段名）**：数据库字段是 `date`，别写成 `data`
- 成果：页面"最近账目"显示数据库真实数据（去写死 ✅）
- ▶️ 详见 `docs/报错手册.md`（症状/原因/解决 已整理）

### P1-3 表单 POST 写库（11-04，已完成）
- **思路一句话**：读表单 → 打包 POST → 后端存 → 重新读刷新。**写数据的流程永远是这样**
- fetch POST 三要素：`method:"POST"` + `headers:{"Content-Type":"application/json"}` + `body: JSON.stringify({...})`（打包成 JSON 字符串）
- 拿表单值：`document.getElementById("id").value`
- 输入框的值是**字符串** → `Number(amount)` 转数字
- 日期：`new Date().toISOString().slice(0,10)` 取今天 `2026-11-04`
- 提交后调 `loadLedger()` 重新拉数据刷新列表（**不用手动刷新页面**）
- 绑定按钮：`document.getElementById("addBtn").onclick = addEntry`
- 成果：表单填 → 点"记下来" → 列表立刻多一条且刷新还在（真存库 ✅）
- ▶️ P1 完成：前后端全通（静态页面 ✅ / 显示真实账 ✅ / 记一笔存库 ✅）

### B 多页导航 + 记收入（11-04，已完成）
- **思路一句话**："多页" = 一个文件里分几个区块(div)，导航控制显示哪个。**不用做多个 html 文件**
- **页面区块**：每页一个 `<div class="page" id="page-xx">` 包起来，默认藏(`display:none`)，点导航才显示(`display:block`)
- **导航切换**：一个 `showPage('xx')` 函数——把别的 `.page` 都去掉 active(隐藏)，把点中的那个加 active(显示)
- **收支区分**：后端给每条账目加 `type` 字段（`income`收入 / `expense`支出），默认 expense
  - 记收入：POST 传 `type:"income"`
  - 饼图只统计支出：SQL `WHERE type='expense'`
  - 本月收入 = `SELECT SUM(amount) WHERE type='income'`（记收入自动加进来，真实反映）
- **数据库兼容旧表**：查列(`PRAGMA table_info`) → 缺 type 就 `ALTER TABLE ADD COLUMN`（旧数据默认 expense）
- 成果：顶部导航 主页/记支出/最近账目；主页有"记一笔收入"；记收入 → 本月收入实时更新
